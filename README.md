Pac-Man — аркадная видеоигра, разработанная японской компанией Namco и вышедшая в 1980 году.
Задача игрока — управляя Пакманом, съесть все точки в лабиринте, избегая встречи с привидениями, которые гоняются за героем. С повышением уровня игры изменяется только её сложность, архитектура лабиринта остаётся идентичной.
 Мы реализовали эту легендарную игру на платформе Arduino, и вы можете повторить этот проект самостоятельно.
Сначала надо скачать Sprites.cpp и Sprites.h в папку с такимже именем.
Далее скачать Mechanic.cpp и Mechanic.h в папку с такимже именем.
Далее эти две папки перенести в папку с библиотеками Arduino.
Если вы проделали ренее прописанные действия то можете скачать файл с программой(PacMan.ino) и jcon схему проекта.
После всех этих действий можете наслаждаться нашим ремёйком этой легендарной игры
